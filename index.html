⚙️ ตั้งค่า Sheet Sync
ตั้งครั้งเดียว เพื่อให้ "เพิ่ม/แก้/ลบ" ในเว็บ เขียนกลับเข้า Google Sheet ให้ทั้งทีมเห็น
ขั้นตอน (ทำครั้งเดียว ~5 นาที)
  1. เปิด Google Sheet หลัก → เมนู Extensions ▸ Apps Script
  2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดด้านล่างนี้ลงไป (กดปุ่ม 📋 คัดลอก)
  3. แก้บรรทัด SECRET ให้เป็นรหัสลับที่ตั้งเอง (จำไว้ ใช้ช่องล่าง)
  4. กด Deploy ▸ New deployment ▸ ⚙️ ▸ Web app
  5. ตั้ง Execute as: Me และ Who has access: Anyone → Deploy → อนุญาตสิทธิ์
  6. คัดลอก Web app URL (ลงท้าย /exec) มาวางในช่องล่าง พร้อมรหัสลับ แล้วกดบันทึก
